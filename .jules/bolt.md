## 2025-02-15 - Pillow (PIL) ImageFont.truetype Caching in Subtitle Loops
**Learning:** In video rendering and subtitle generation workflows, Pillow's `ImageFont.truetype` is often called for every single subtitle segment/line. TrueType/OpenType font files (especially multi-megabyte CJK fonts like `STHeitiMedium.ttc`) are read and parsed from disk on every call, leading to extreme and redundant CPU and disk I/O overhead. Caching these font instances with Python's built-in `@lru_cache` eliminates this overhead entirely. However, because fonts can also be loaded from unhashable objects (e.g., file-like stream objects), the caching layer must defensively bypass the cache for unhashable arguments using a `try-except TypeError` check to prevent runtime crashes.
**Action:** Always wrap `ImageFont.truetype` with a helper that handles hashability checks before querying a cached loader to safely optimize font instantiation in loops.
