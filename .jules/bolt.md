## 2026-11-02 - Punctuation checks, sentence splitting, and root directory resolution
**Learning:** `os.path.realpath(__file__)` incurs repeated filesystem traversal and stat system calls on every storage, task, resource, font, and song directory lookup; precomputing `_ROOT_DIR` at module initialization speeds up `root_dir()` by ~200x. Additionally, checking characters against linear lists in punctuation loops can be optimized using precomputed `set` lookups (`not PUNCTUATION_SET.isdisjoint(word)`) and accumulating string characters in lists to eliminate repeated string copies, speeding up sentence splitting by ~2.2x.
**Action:** Precompute static filesystem roots at module load and use `set.isdisjoint` alongside list accumulation for frequent per-character text processing loops.
