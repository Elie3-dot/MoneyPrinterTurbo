## 2026-11-11 - Cache PIL ImageFont loading in video/subtitle generation loops
**Learning:** During video subtitle generation in `app/services/video.py`, Pillow's `ImageFont.truetype(font, fontsize)` was called per subtitle line (both in `wrap_text` and repeatedly when calculating dimensions for rounded backgrounds in `create_text_clip`). Loading and re-parsing large `.ttc`/`.ttf` font files (which can be 16MB–55MB in `resource/fonts/`) repeatedly from disk adds unnecessary CPU parsing and disk I/O latency to every subtitle element. Caching `ImageFont.truetype` instances using `@lru_cache` for font path strings achieves ~195x faster font lookups (~0.23ms vs ~45ms for 200 lookups).
**Action:** When working with PIL fonts inside rendering or formatting loops, wrap font loading in an LRU cache or reuse loaded `ImageFont` instances across iterations while defensively bypassing caching for unhashable arguments.
